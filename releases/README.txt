LisaFuji Browser 1.1 beta for the Apple Lisa Office System       October 2026 (release build REV Q)
A text web browser through an RS-232 FujiNet and the LisaWeb gateway.  Tool 419314.

New in this build: the speed set from the Lisa.  Speed > Use 19200 baud posts the new speed to the FujiNet's own web page
through its network device, restarts it and follows it; the first port open of each launch probes for the speed, so
the tools follow one another.  Floppy image LISAFUJI_BROWSER_1_1.dc42; the source zip has the Lisa Pascal sources and the exec files.
Needs an RS-232 FujiNet (FutureVision Research) on Serial B.  Built with the Lisa Workshop 3.0 in LisaEm;
tested on a Lisa 2/10.
