LisaFuji Browser 1.2 beta for the Apple Lisa Office System       30 October 2026 (release build REV S)
A text web browser through the LisaWeb gateway.  Tool 419314.

New in this build: works through an ESPFuji ESProFile (https://github.com/GyroPilot/ESPFuji) as well as an RS-232
FujiNet or a LisaNet: put the tool on the ESProFile's volume and it finds the mailbox at launch, no serial adapter.
Otherwise the 1.1 beta browser.  Floppy image LISAFUJI_BROWSER_1_2_BETA.dc42; the source zip has the Lisa Pascal
sources, the exec files and the gateway.  Built with the Lisa Workshop 3.0 in LisaEm; the ESProFile route is the unit
proven in LisaFuji 1.2 on a Lisa 2/10, not yet run with the Browser on a Lisa (hence beta).
